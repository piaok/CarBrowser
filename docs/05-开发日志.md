## 模块1：TV适配基础 (M01)

### T01: 创建projector分支 + Manifest改造

- Manifest 新增 `uses-feature android.hardware.touchscreen` (required=false)

### T02: 暗色主题 + Overscan + 资源
- 新建 `styles_tv.xml`：Theme.LazyLines.TV（继承 NoActionBar 暗色主题）

- 新建 `dimens_tv.xml`：overscan_padding=56dp, side_nav_width=72dp 等
- 新建 drawable：
  - `tv_focusable_bg.xml` — 焦点时 accent 边框 + 半透明背景
  - `tv_nav_item_bg.xml` — 侧边栏项焦点/激活态
  - `tv_panel_item_bg.xml` — 面板项焦点态
  - `tv_banner.xml` — TV launcher banner
  - `ic_search.xml` — 搜索图标
  - `ic_shield.xml` — 广告拦截盾牌图标

## 模块2：D-pad导航框架 (M02)

### T03: TVFocusManager
- 双 Zone 架构：NAV（侧边栏）和 CONTENT（内容区）
- DPAD_LEFT/RIGHT：Zone 切换
- DPAD_UP/DOWN：NAV zone 内焦点移动 / CONTENT zone 内 WebView scroll
- WebView 内部不拦截焦点，靠 scroll 浏览网页
- 提供 OnZoneSwitchListener 回调

## 模块3：TV UI层 (M03)

### T04: activity_tv_main.xml 布局
- 根布局 FrameLayout，子元素 safe_area LinearLayout 带 overscan padding
- 左侧 side_nav：6个 ImageButton（首页/搜索/书签/视频/下载/设置）
- 右侧 content_zone：地址栏 + ProgressBar + tab_container
- 覆盖层 panel_overlay：书签/视频工具/设置面板

### T03: TVMainActivity (核心Activity)
- 替代 HomeActivity + BrowserActivity 的单 Activity 架构
- 初始化 TVFocusManager、TabManager、VideoDetector、DownloadManager
- 侧边栏按钮点击事件：
  - 首页 → 加载 homepage.html
  - 搜索 → 聚焦地址栏
  - 书签 → 弹出书签面板
  - 视频 → 弹出视频工具面板
  - 下载 → DownloadDialog
  - 设置 → 弹出设置面板
- 面板系统：panel_overlay + panel_container，D-pad 可导航
- 遥控器 BACK 关闭面板，再按退回/退出

### T07: 面板实现
- **书签面板**：列出所有书签，D-pad 聚焦后点击跳转
- **视频工具面板**：检测视频/手动输入URL/播放已检测视频
- **设置面板**：广告拦截开关/搜索引擎选择/安全区调整(5/10/15%)
- 所有面板项使用 tv_panel_item_bg 焦点态，18sp 字体

## 模块4：WebView适配 (M04)

### T05: 分辨率修正 + 投影阅读模式
- `setInitialScale((dm.densityDpi / 160.0 * 100).toInt())` 修正 TV WebView 分辨率
- `setTextZoom(130)` 增大字体，适配投影 3 米阅读
- `setUseWideViewPort(true)` + `setLoadWithOverviewMode(true)` 适配宽屏
- Overscan padding 通过 `safeArea.setPadding()` 实现，默认10%，可5/10/15%切换

## 模块5：ExoPlayer TV适配 (M05)

### T06: VideoActivity 遥控器控制
- DPAD_CENTER = 播放/暂停
- DPAD_LEFT = 快退10秒 / 长按=倍速快退
- DPAD_RIGHT = 快进10秒 / 长按=倍速快进
- BACK = 退出全屏
- 倍速档位：1x→1.5x→2x→3x→4x→8x
- VideoPlayerService 新增 `setSpeed(float)` 方法
