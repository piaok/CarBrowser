# 需求规格说明书 — LazyLines Browser for Projector

> 阶段1产出 | 日期：2026-05-11

## 1. 项目概述

LazyLines Browser 投影仪版是从车机浏览器 LazyLines（CarBrowser）fork 出的 Android TV 专用版本，面向 **NVIDIA Shield TV 2017 Pro** + **BenQ W1070+ 投影仪** 场景。核心目标是让用户通过遥控器 D-pad 在投影大屏上流畅浏览网页、观看视频，同时复用 LazyLines 已有的 WebView 内核、视频检测、下载管理和广告拦截能力。

## 3. 用户场景

### 场景1：投影大屏浏览新闻

- **角色**：家庭用户，坐在沙发上
- **前置条件**：Shield TV 已开机，投影仪已投射 100寸画面
- **操作流程**：TV 主屏选择 LazyLines → 进入浏览器首页 → D-pad 选择搜索框 → 输入"今日新闻" → 浏览搜索结果 → 上下滚动阅读
- **预期结果**：字体清晰可读（3米距离），焦点指示明确，无触屏操作

### 场景2：在线视频观看

- **角色**：家庭用户
- **前置条件**：已浏览到视频页面
- **操作流程**：视频检测自动弹出提示 → D-pad 确认播放 → ExoPlayer 全屏播放 → 遥控器控制暂停/进度/倍速
- **预期结果**：视频流畅播放（1080p），ExoPlayer 遥控器适配完善

### 场景3：下载文件到 Shield TV

- **角色**：家庭用户
- **前置条件**：已找到下载链接
- **操作流程**：D-pad 选中下载链接 → 确认下载 → 下载管理器显示进度 → 完成后可查看文件
- **预期结果**：文件保存到 Shield TV 存储，可通过文件管理器访问

## 4. 约束条件

- **技术约束**：
  - 目标设备：NVIDIA Shield TV 2017 Pro（Tegra X1, 3GB RAM, Android 11, 16GB eMMC）
  - 显示设备：BenQ W1070+（1080p DLP, 2200 lumens, HDMI 1.4a, ~33ms input lag）
  - 开发语言：Java 8（保持与 LazyLines 车机版代码库兼容）
  - UI 框架：传统 View 系统（不迁移 Compose for TV，保持 Java 8 兼容）
  - 最低 API：21（Android 5.0），目标 API：30（Android 11）
  
- **业务约束**：
  - 必须从 LazyLines 车机版 fork，不做独立项目
  - 复用核心逻辑（WebView/视频检测/下载/广告拦截），只改 UI 层和 TV 适配层
  - APK 体积控制在 10MB 以内（Shield TV 存储有限）
  
- **性能约束**：
  - 冷启动 ≤3秒
  - 页面加载后 D-pad 焦点切换响应 ≤100ms
  - ExoPlayer 视频起播 ≤2秒
  - 内存占用 ≤150MB（3GB RAM 设备上留足余量）
  
- **安全约束**：
  - 不要求 Google Play 上架（侧载分发）
  - 保留 SSL 容错（部分视频站证书问题）
