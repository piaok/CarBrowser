5. Overscan 安全区设计

参数值说明
默认安全区比例10%（每边）1080p下每边约54px，总计108px
实现方式Activity根布局 setPadding()所有子View自动在安全区内
可配置Settings → 安全区调整5%/10%/15% 三档可选
调试模式橙色半透明边框Settings中可开启overscan辅助线

6. 投影仪适配

6.1 DLP 投影色彩补偿

问题补偿策略
DLP色域偏窄，蓝色偏暗焦点高亮色使用 #4FC3F7（偏亮蓝），避免深蓝
暗部细节丢失背景色不低于 #0D0D0D，前景不低于 #F0F0F0，对比度 >10:1
彩虹效应（单DLP轮）减少大面积纯白闪烁，过渡用渐变
33ms 输入延迟焦点切换动画 ≤100ms，避免长动画造成"拖影感"

6.2 投影阅读模式

参数值说明
WebView textZoom130比默认大30%，3米投影距离可阅读
全局最小字体18sp所有原生UI文字不小于此值
焦点指示器3dp光晕 + scale 1.083层视觉反馈：边框+光晕+缩放
行间距1.5x原生列表项增加行高

7. 核心交互流程

7.1 冷启动流程

TV Launcher 点击 LazyLines 图标 → TVMainActivity.onCreate() → 设置 overscan padding → 应用暗色主题 → WebView scale fix → 加载首页 (file:///android_asset/homepage.html) → 焦点自动落在首页搜索框 → 用户 D-pad 操作开始

7.2 搜索流程

D-pad 聚焦搜索框 → DPAD_CENTER 打开系统输入法 → 输入关键词 → 确认提交 → UrlBarHandler.processInput() → 判断 URL vs 搜索关键词 → WebView 加载结果页面 → 焦点自动回到 Content Zone → ▲▼ 滚动浏览结果

7.3 视频检测流程

页面加载完成 → VideoDetector JS 注入 → 扫描 <video>/<source>/<iframe> → MutationObserver 监听动态内容 → 检测到视频 → 右下角弹出 ▶ 播放 按钮 → DPAD_CENTER → ExoPlayer 全屏播放 → 遥控器控制播放 → BACK → 退出全屏回到浏览
